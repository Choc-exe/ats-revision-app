# Fiche Synthèse — Séries Numériques et Séries de Fourier

<CriticalFormula title="1. Critères de convergence des séries numériques">
$$\sum_{n\ge 1}\frac{1}{n^\alpha} \text{ converge} \iff \alpha > 1 \quad ; \quad \sum_{n\ge 0} q^n = \frac{1}{1-q} \iff |q| < 1$$

$$\text{Alternées : } \sum (-1)^n a_n \text{ converge si } a_n \ge 0,\; (a_n)\searrow \text{ et } \lim a_n = 0$$
</CriticalFormula>

<CriticalFormula title="2. Formulaire Séries de Fourier (Pulsation ω = 2π/T)">
$$a_0 = \langle f \rangle = \frac{1}{T}\int_0^T f(t)\,\mathrm{d}t \quad ; \quad a_n = \frac{2}{T}\int_0^T f(t)\cos(n\omega t)\,\mathrm{d}t \quad ; \quad b_n = \frac{2}{T}\int_0^T f(t)\sin(n\omega t)\,\mathrm{d}t$$

$$\text{Dirichlet : } S_f(t) = \frac{f(t^+) + f(t^-)}{2} \quad ; \quad \text{Parseval : } \frac{1}{T}\int_0^T f(t)^2\,\mathrm{d}t = a_0^2 + \frac{1}{2}\sum_{n=1}^{+\infty}(a_n^2 + b_n^2)$$
</CriticalFormula>

| Propriété de symétrie du signal $f(t)$ | Conséquence immédiate sur les coefficients de Fourier |
| :--- | :--- |
| **Signal pair** : $f(-t) = f(t)$ | Tous les coefficients sinus sont nuls : **$\forall n \ge 1,\; b_n = 0$** |
| **Signal impair** : $f(-t) = -f(t)$ | Tous les coefficients cosinus sont nuls : **$a_0 = 0$ et $\forall n \ge 1,\; a_n = 0$** |
| **Signal alterné (anti-périodique)** : $f(t + T/2) = -f(t)$ | Tous les harmoniques de rang **pair** sont nuls ($a_{2p} = b_{2p} = 0$) |
