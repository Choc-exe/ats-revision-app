## L'Essentiel du Bulletin Officiel ATS

* **Électrostatique du vide** :
  * Champ d'une charge ponctuelle : $\vec{E} = \frac{q}{4\pi\varepsilon_0 r^2}\vec{u}_r$ ; Lien au potentiel : **$\vec{E} = -\overrightarrow{\text{grad}}\,V$**.
  * Symétries de $\vec{E}$ (vrai vecteur) : contenu dans $\Pi^+$, orthogonal à $\Pi^-$.
  * **Théorème de Gauss** : **$\oiint_\Sigma \vec{E}\cdot\mathrm{d}\vec{S} = \frac{Q_{\text{int}}}{\varepsilon_0}$** (Plan infini : $E = \frac{\sigma}{2\varepsilon_0}$).
  * **Condensateur plan** : **$C = \frac{\varepsilon_0 S}{e}$**, $q = C\,u$ et densité d'énergie **$w_e = \frac{1}{2}\varepsilon_0 E^2$**.
* **Conduction électrique** :
  * Densité de courant : $\vec{j} = \rho_m\vec{v}$, intensité $I = \iint \vec{j}\cdot\mathrm{d}\vec{S}$.
  * Conservation de la charge : $\frac{\partial \rho}{\partial t} + \text{div}(\vec{j}) = 0$ (en régime stationnaire $\text{div}(\vec{j}) = 0 \implies$ loi des nœuds).
  * **Loi d'Ohm locale** : **$\vec{j} = \sigma\,\vec{E}$** $\implies$ résistance d'un cylindre **$R = \frac{\ell}{\sigma S}$**.
* **Magnétostatique du vide** :
  * Force de Lorentz : $\vec{F}_m = q\vec{v}\wedge\vec{B}$ ($\mathcal{P} = 0$) ; Force de Laplace : **$\vec{F}_L = I\,\vec{AB}\wedge\vec{B}$**.
  * Moment magnétique : $\vec{m} = I\,S\,\vec{n}$ ; Couple subi : $\vec{\Gamma} = \vec{m}\wedge\vec{B}$.
  * Symétries de $\vec{B}$ (pseudo-vecteur) : orthogonal à $\Pi^+$, contenu dans $\Pi^-$ ; flux conservatif ($\oiint \vec{B}\cdot\mathrm{d}\vec{S} = 0$).
  * **Théorème d'Ampère** : **$\oint_\mathcal{C} \vec{B}\cdot\mathrm{d}\vec{\ell} = \mu_0 I_{\text{enlacé}}$** (Fil infini : $B = \frac{\mu_0 I}{2\pi r}$ ; Solénoïde infini : **$B = \mu_0 n I$**).
* **Induction & Rails de Laplace** :
  * **Loi de Faraday** : **$e = -\frac{\mathrm{d}\Phi}{\mathrm{d}t}$** (modération de Lenz).
  * Solénoïde long : $L = \mu_0 n^2 \mathcal{V} = \frac{\mu_0 N^2 S}{\ell}$ et densité d'énergie **$w_m = \frac{B^2}{2\mu_0}$**.
  * **Rails de Laplace** : $e = -B\ell v$, $F_L = i B \ell$ et couplage parfait **$\mathcal{P}_{\text{Laplace}} + e\,i = 0$**.
