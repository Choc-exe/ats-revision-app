## L'Essentiel du Bulletin Officiel ATS

* **Liaisons normalisées & Degrés de liberté ($m$ mobilités sur 6)** :
  * Encastrement ($0$), Glissière ($1T$), Pivot ($1R$), Hélicoïdale ($1$ couplé : $v = \frac{p}{2\pi}\omega$), Pivot glissant ($1T + 1R$), Appui plan ($2T + 1R$), Rotule / Sphérique ($3R$), Linéaire annulaire ($1T + 3R$), Linéaire rectiligne ($2T + 2R$), Ponctuelle ($2T + 3R = 5$)[cite: 41].
* **Dérivation vectorielle & Torseur cinématique** :
  * **Formule de Bour** : **$\left(\frac{\mathrm{d}\vec{U}}{\mathrm{d}t}\right)_{\mathcal{R}_0} = \left(\frac{\mathrm{d}\vec{U}}{\mathrm{d}t}\right)_{\mathcal{R}_1} + \vec{\Omega}(\mathcal{R}_1/\mathcal{R}_0) \wedge \vec{U}$**[cite: 126, 134].
  * **Changement de point (Varignon / `BABAR`)** : **$\vec{V}(B \in 2/1) = \vec{V}(A \in 2/1) + \vec{BA} \wedge \vec{\Omega}(2/1)$**[cite: 42, 46].
  * **Composition des mouvements (au même point $A$)** : $\mathcal{V}(2/0) = \mathcal{V}(2/1) + \mathcal{V}(1/0)$[cite: 41, 42].
  * **Condition de Roulement Sans Glissement (RSG) en $I$** : **$\vec{V}(I \in 2/1) = \vec{0} \iff \vec{V}(I \in 2/0) = \vec{V}(I \in 1/0)$**[cite: 41].
* **Fermetures & Transmetteurs de puissance (Trains épicycloïdaux HP)** :
  * **Fermeture géométrique** : $\vec{AB} + \vec{BC} + \vec{CA} = \vec{0}$ projetée dans $\mathcal{B}_0$[cite: 45, 126].
  * **Vis-écrou (pas $p$)** : **$v = \frac{p}{2\pi}\omega$** ; **Pignon-crémaillère (rayon $R$)** : **$v = R\,\omega$**[cite: 46].
  * **Train d'engrenages simple** ($k$ contacts extérieurs) : **$r = \frac{\omega_s}{\omega_e} = (-1)^k \frac{\prod Z_{\text{menantes}}}{\prod Z_{\text{menées}}}$**[cite: 46].
